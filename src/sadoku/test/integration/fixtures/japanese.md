# 日本語ドキュメントの表示サンプル

本文、見出し、表、コードに含まれる日本語と英数字の見え方を確認するためのサンプルです。
数字の比較では、通常の本文とインラインコードをそれぞれ確認してください。

## 本文の読みやすさ

ドキュメントを読むときは、一文字ずつの判別しやすさに加えて、文章全体の流れも大切です。
漢字が続く箇所、ひらがなの多い箇所、英単語や数字が混ざる箇所を読み比べると、字形や余白の違いを確認できます。

このサービスでは、利用者が登録した資料をブラウザーで閲覧し、気になった箇所にコメントを残せます。
レビューの対象には、設計書、議事録、運用手順書などがあります。
変更の目的と影響範囲を最初に説明し、その後に具体的な操作や確認結果を記載すると、初めて読む人にも内容が伝わりやすくなります。

たとえば、API の応答時間が 120 ms から 85 ms
に短縮された場合は、測定条件もあわせて記録します。 対象のリクエスト数は 1,000
件、計測期間は 2026 年 10 月 1 日から 10 月 7 日までとします。 同じ処理を 3
回実行し、結果に大きなばらつきがないことを確認しました。

## 日本語と英字の混在

日本語の本文に Markdown、TypeScript、HTTP API、GitHub、Noto Sans JP
などの英字を混ぜた例です。 バージョン番号は v1.2.3、識別子は
DOC-001、問い合わせ番号は ISSUE-1234 とします。

形の似た文字：I l 1 ／ O o 0 ／ B 8 ／ S 5

単語と文章：minimum、ILLUSTRATION、Hello, world!、Save changes、Preview document

ひらがな：あいうえお、かきくけこ、さしすせそ、ぱぴぷぺぽ、ぁぃぅぇぉ、っゃゅょ。

カタカナ：アイウエオ、カキクケコ、ヴァイオリン、ネットワーク、ユーザーインターフェース。

漢字と異体字：確認、設計、議論、閲覧、鬱、髙橋、𠮷野。

句読点と記号：「引用」、『書名』、（補足）、【重要】、！？、……、〜、→、※。

## 日本語を含むコード

本文の数字 0123456789 と、次のコード内の数字を比較できます。

```typescript
// 日本語のコメントと、英数字の識別子を混在させた例です。
const report = {
  title: "週次レポート",
  documentId: "DOC-001",
  total: 1234567,
  completionRate: 98.5,
  digits: "0123456789",
};

console.log(`${report.title}: ${report.total} 件`);
```

コードの直後に続く本文です。日本語、English、数字 12345
を続けて読み、書体の切り替わりや段落の間隔を確認できます。
