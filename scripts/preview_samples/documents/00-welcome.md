# Previewの動作確認

起動直後から操作を試せるサンプルです。各文書を開いて確認してください。

| 文書                                        | 確認できること                                                               |
| ------------------------------------------- | ---------------------------------------------------------------------------- |
| [レビュー](01-review.md)                    | 未解決・解決済みコメント、人とbot、返信、再レビュー依頼、instruction、memory |
| [本文の変更](02-changes.md)                 | 前回との差分、変更前の引用、コメント位置の追従、コメント対象の削除           |
| 削除済みの文書（03-archived.md）            | ファイル削除後の保存された本文・コメント・memory                             |
| [空の状態](04-empty.md)                     | コメント・instruction・memoryがない状態、新規コメントの作成                  |
| [Markdownの表示](examples/comprehensive.md) | 見出し、表、コード、Mermaidなど                                              |
| [日本語の表示](examples/japanese.md)        | 日本語、数字、英字の読みやすさ                                               |

コメントの追加・編集・削除・返信・解決などを自由に試せます。
タグと表示タイトルの初期設定は行っていません。画面から設定して試せます。

操作結果は同じインスタンスが動いている間だけ残ります。
再起動・再デプロイで初期状態に戻ります。インスタンス間では操作結果を共有しません。
