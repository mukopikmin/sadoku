# レビューのサンプル

未解決・解決済みコメント、人とbotの返信、再レビュー依頼を確認できます。
instructionとmemoryにもサンプルを登録しています。

## 基本の操作

利用者はMarkdownを読み、気になる箇所にコメントを残せます。

レビュー結果は文書ごとに整理します。

解決した指摘も後から読み返せます。

## 確認リスト

- [ ] 手順の説明を確認する
- [x] 表とコードの表示を確認する

## 進捗

| 作業     | 担当   | 状態   |
| -------- | ------ | ------ |
| レビュー | 担当者 | 確認中 |
| 表示確認 | bot    | 完了   |

## 実装例

```typescript
const status = "ready";
console.log(status);
```
