# Work documents

This directory holds committed plans, investigations, migration reports, and
verification notes. Maintained documentation belongs outside this directory.

Start each document with:

```text
Purpose: What this document supports.
Related issue/PR: A link, or "None recorded".
Deletion condition: The concrete outcome that makes this document unnecessary.
```

When finishing the related work, check the deletion condition. Preserve useful
long-term knowledge in maintained documentation or a README beside the relevant
code or fixtures, then remove completed work documents. Git history retains
their contents. During cleanup, review this directory for conditions that have
already been met; do not delete notes solely because they are old.
